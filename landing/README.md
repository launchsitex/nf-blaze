# NF-Blaze · דף הנחיתה (nf-blaze.dev)

אתר סטטי, עברית RTL, **בלי שלב build ובלי תלויות** — שלושה קבצים ותמונה אחת.

```
landing/
├── index.html      עמוד הבית
├── styles.css      מערכת העיצוב — אותה פלטה של האפליקציה
├── sprite.js       סט האייקונים, משותף לכל העמודים
├── app.js          תפריט מובייל, חשיפה בגלילה, אנימציית הקונסולה, שליחת הטופס
├── config.js       כתובת ה-API, מפתח publishable, וקישור ההורדה
├── favicon.svg
└── guides/         מדריכי חיבור מודל — נגישים מתפריט «מדריכים»
    ├── index.html  ריכוז שלושת המדריכים
    ├── chatgpt.html
    ├── gemini.html
    └── claude.html
```

## המדריכים

שלושה עמודים שמסבירים למי שלא עשה את זה מעולם איך להשיג מפתח API ולחבר
אותו למערכת, כולל פרק אבטחה בכל אחד. הם מגיעים מהתפריט העליון (נפתח בריחוף)
ומהתפריט במובייל.

**התוכן אומת מול התיעוד הרשמי של הספקים באוגוסט 2026.** שלושה דברים שהיו
שגויים בכל המדריכים הישנים ברשת ותוקנו כאן:

| | מה שרוב המדריכים אומרים | המצב בפועל |
|---|---|---|
| קונסולת Anthropic | `console.anthropic.com` | עברה ל-**`platform.claude.com`** (הישנה מפנה) |
| מפתח Gemini | מתחיל ב-`AIza…` | מתחיל ב-**`AQ.…`**; מפתחות `AIza` **ייפסלו אחרי ספטמבר 2026** |
| תיעוד OpenAI | `platform.openai.com/docs` | עבר ל-`developers.openai.com` (הקונסולה נשארה) |

⚠️ **שווה לבדוק בעין לפני פרסום:** שמות הכפתורים המדויקים ליצירת מפתח
ב-OpenAI וב-Anthropic — הדפים חסומים מאחורי התחברות ולא ניתן היה לאמת אותם
אוטומטית. אם השם על המסך שונה — לעדכן בעמוד המתאים.

## העלאה לאוויר

מעלים את חמשת הקבצים לשורש האחסון של `nf-blaze.dev`. כל אחסון סטטי מתאים
(Hostinger, Vercel, Netlify, Cloudflare Pages).

## מה צריך למלא ב-`config.js`

| שדה | מצב |
|-----|-----|
| `requestEndpoint` | ✅ מוגדר — ‏`request-license` נפרסה ונבדקה |
| `anonKey` | ✅ מוגדר (מפתח publishable, אינו סוד) |
| `downloadUrl` | ❌ **ריק** — כל עוד כך, כפתור ההורדה מפנה לטופס בקשת הרישיון במקום לקישור שבור |
| `contactEmail` | ✅ `Info@nf-blaze.dev` |

## טופס בקשת הרישיון

הטופס שולח ל-Edge Function `request-license`, והיא **שומרת את הבקשה בטבלה
`nfb_license_requests`** בפרויקט `ilsidpixxkfwowsnkntg`. הבקשות מנוהלות
בפורטל הרישיונות, בטאב **«בקשות רישיונות»** — עם סינון, אישור, דחייה ומחיקה.

השדות: שם מלא · אימייל · «איך הגעת אלינו?» (פייסבוק / גוגל / המלצה / אחר) ·
מה תרצה לבנות. **כולם חובה**, ונאכפים גם בדפדפן וגם בשרת.

הטופס מבטיח שהמפתח יישלח במייל **תוך 48 שעות** — ההבטחה מופיעה גם בטקסט
המקדים וגם בתיבה מעל כפתור השליחה. שווה לעמוד בזה.

**הגנות בפונקציה:** מלכודת בוטים (שדה מוסתר — בוט שממלא אותו מקבל «הצלחה»
מזויפת ולא לומד מה נכשל), אימות כל השדות, חיתוך אורך, ומגבלת קצב של
3 בקשות ל-10 דקות לכל כתובת IP.

**הגנת המסד:** הכנסה אפשרית רק ב-`service_role`, כלומר דרך הפונקציה בלבד.
ניסיון להזריק בקשות ישירות מהדפדפן עם המפתח הציבורי מוחזר ב-401, וקריאה
אנונימית מחזירה רשימה ריקה. אומת בפועל.

> **Resend אינו בשימוש יותר** בזרימה הזו, והסוד `RESEND_API_KEY` אינו נדרש.
> אם בעתיד תרצה גם התראה במייל על בקשה חדשה — זו תוספת לפונקציה, לא החלפה
> של השמירה במסד.

## תאימות ונגישות — מה נבדק בפועל

- **אין גלישה אופקית** ב-320 / 390 / 430 / 768 פיקסלים (נמדד `scrollWidth === clientWidth`).
- **כל יעדי המגע מעל 44px** — נמדד על כל הכפתורים, הקישורים בתפריט וכותרות ה-FAQ.
- **אין טקסט מתחת ל-12px.**
- שדות הטופס ב-`font-size: 16px` — מונע זום אוטומטי ב-iOS בעת מיקוד.
- `viewport-fit=cover` + `env(safe-area-inset-*)` בניווט ובפוטר — לאייפונים עם מגרעת.
- `100dvh` בתפריט המובייל — לא נחתך על ידי סרגל הכתובת בספארי.
- **`prefers-reduced-motion`** — הגחלים והכתמים נעלמים, האנימציות מתבטלות, והקונסולה
  מוצגת מלאה מיד.
- שאלות נפוצות בנויות מ-`<details>` — עובדות גם בלי JavaScript.

## דיוק התוכן

הטקסט נכתב מול קריאה של הקוד עצמו, לא מהזיכרון. שלוש נקודות שחשוב לא לשבור
בעריכות עתידיות:

- **אין תקופת ניסיון.** בוטלה ב-1.57.0 (`TRIAL_DAYS = 0`). ‏`README.md` הראשי
  עדיין מזכיר «14 יום ניסיון» — זה מיושן ואסור לצטט אותו.
- **‏Vercel עדיין לא בחיבור OAuth בלחיצה.** העמוד מדבר על פרסום מיידי בלי חשבון
  (שנכון) ולא על «התחבר בלחיצה» — אין לשנות עד שהאינטגרציה תירשם.
- **לא לכתוב «מוצפן תמיד»** על מפתחות ה-API. יש נפילה לאחסון גלוי אם מערכת
  ההפעלה לא מספקת הצפנה; הניסוח בעמוד הוא «דרך מנגנון ההצפנה של מערכת ההפעלה».
